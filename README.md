# Mahmoodiyah Packaging — Custom Packaging Solutions

A modern, high-performance web platform and digital portfolio for **Mahmoodiyah**, specializing in custom packaging solutions, Bleach Card (SBS) folding cartons, Box Board duplex cartons, luxury rigid setup boxes, custom paper bags, and blister backer cards.

## Features

- **Selected Client Portfolio**: Showcasing real packaging work for brands including Rivaj UK, Benson Automotive, More Macaroni / Brunos, Olina Cosmetics, Dezato Bakery, MAQ Baby Care, Fun Kids Care, and Shifa Labs.
- **Finishing & Embellishments**: Highlighting Golden Panni (hot gold foil stamping), multi-color foil, soft-touch matte lamination, spot UV, and precision embossing.
- **Modern Responsive Design**: Built with Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS.
- **Direct B2B Communication**: Instant WhatsApp and phone inquiry integration (`0302-4598791` and `0323-4866931`).

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Production Build

To test and build the production bundle:

```bash
npm run build
npm start
```
